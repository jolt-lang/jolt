# host/chez/portability-blocklist.txt — FORBIDDEN Chez-only identifiers the host
# may not use directly, regardless of target. Rounds R4-R9 of the
# portable-scheme-layer epic route each tier behind capability entry points in
# host/scheme-adapter/chez.ss. The end state (R10) is structural, not zero
# lines: the allowlist (portability-allowlist.txt) may only name TARGET-OWNED
# files — per-target implementations a port replaces rather than migrates
# (today: host/chez/scheme-adapter-runtime.ss and host/chez/hasheq.ss). An
# allowlist line naming any other file fails the gate regardless of whether its
# hit is real: a real forbidden-name use in a normal file is routed through the
# adapter, never allowlisted. This file grows with what the census finds.
#
# Names every target's adapter must provide moved to
# host/scheme-adapter/CONTRACT.txt in R2 (threads, system basics, and the misc
# universal primitives: boxes, format, sort, gensym, SRFI-1/SRFI-43 ops,
# hashtable extensions). The gate allows those everywhere — no allowlist lines.
# What remains here is the genuinely never-portable core: FFI, eval/compile,
# fasl, introspection, GC hooks, and Chez-only list/vector odds.
#
# Format: one identifier per line, tiers are "# tier: <name>" headers. A tier whose
# name starts with "srfi-" is linted but wholesale-allowlisted: the census counts
# it, the gate never fails on it (parameterize/make-parameter are SRFI-39 — present
# in every serious Scheme, not worth per-file allowlist lines while R2+ decides
# their migration).
#
# R6RS check: every entry is non-R6RS, OR an R6RS-library member whose host call
# shape is Chez-flavored and owned by a later round (noted inline). Verified-still
# standard names are dropped rather than listed: make-eq-hashtable, make-eqv-
# hashtable, symbol-hashtable?, list-sort, vector-sort, vector-sort!, guard,
# time-second, time-nanosecond, eval, environment, exit,
# command-line, condition-continuation, make-continuation-condition,
# continuation-condition?, and the fx/fl/bytevector/vector/string R6RS arithmetic
# are all standard R6RS and deliberately absent. `exit`/`eval` are standard, but
# the host's Chez-ENV-SPECIFIER call sites ((environment '(chezscheme))) are real
# migration work — tracked by R8, not by this gate.
#
# A name can also be standard on EVERY target and still belong here: string-copy!
# is (from from-start to to-start count) on Chez and (to at from start end) on
# R7RS/SRFI-13 (Gambit, Guile). Same arity, opposite direction, so a raw call in
# shared code compiles on both and on the R7RS target copies the empty
# destination into the source. It goes through sa-string-copy-range!
# (CONTRACT.txt), which fixes the R7RS order.
#
